# TOP MUSIC 🎵

بوت موسيقى لديسكورد بتصميم أسود وذهبي، مبني باستخدام Discord.js وLavalink.

## المميزات
- تشغيل أغنية بالبحث أو الرابط من مصادر يدعمها Lavalink.
- قائمة انتظار، تخطي، إيقاف مؤقت واستكمال.
- تحكم في الصوت من 1 إلى 100.
- تكرار الأغنية أو القائمة.
- خلط القائمة، حذف أغنية، ومسح المنتظر.
- أزرار تحكم في رسالة Now Playing.
- إعادة اتصال تلقائية وإعادة تشغيل الحاويات بعد الأعطال.

## المتطلبات
- Discord Application وبوت من Discord Developer Portal.
- VPS أو استضافة Docker تعمل باستمرار.
- Docker Engine + Docker Compose.
- Node.js 22.12+ إذا شغّلت البوت خارج Docker.
- Lavalink v4 يحتاج Java 17+ (صورة Docker الرسمية تتضمن بيئة التشغيل).

## 1) إنشاء البوت
1. افتح https://discord.com/developers/applications
2. أنشئ Application باسم TOP MUSIC.
3. من Bot أنشئ/أعد ضبط Token وانسخه بسرية.
4. من OAuth2 > URL Generator اختر scopes: `bot` و`applications.commands`.
5. اختر صلاحيات: View Channels, Send Messages, Embed Links, Connect, Speak, Use Application Commands.
6. افتح رابط الدعوة وأضف البوت لسيرفرك.
7. فعّل Developer Mode في Discord وانسخ Application ID وServer ID.

لا تشارك Token مع أي شخص ولا ترفعه إلى GitHub.

## 2) الإعداد
1. انسخ `.env.example` إلى ملف اسمه `.env`.
2. ضع `DISCORD_TOKEN` و`CLIENT_ID`.
3. ضع `GUILD_ID` لسيرفر الاختبار (اختياري لكنه أسرع).
4. غيّر `LAVALINK_PASSWORD` في `.env` و`lavalink/application.yml` إلى نفس كلمة مرور طويلة وعشوائية.
5. لا ترفع `.env` إلى GitHub.

## 3) تشغيل دائم بـ Docker
من مجلد المشروع:
```bash
docker compose up -d
```
لمشاهدة السجلات:
```bash
docker compose logs -f bot
docker compose logs -f lavalink
```
إيقاف:
```bash
docker compose down
```
الحاويات تستخدم `restart: unless-stopped`، لكن استمرار العمل 24 ساعة يعتمد على بقاء VPS/الاستضافة شغالة وعدم تجاوز حدودها.

## 4) تسجيل أوامر Slash
نفّذ مرة واحدة بعد تعبئة `.env`:
```bash
docker compose exec bot npm run register
```
إذا لم تستخدم `GUILD_ID`، فالأوامر العامة قد تستغرق وقتاً حتى تظهر.

## 5) أوامر البوت
- `/play song` تشغيل أغنية أو رابط
- `/join` دخول الروم الصوتي
- `/pause` إيقاف مؤقت
- `/resume` استكمال
- `/skip` تخطي
- `/stop` إيقاف ومسح المشغل
- `/leave` خروج
- `/queue` قائمة التشغيل
- `/nowplaying` الأغنية الحالية وأزرار التحكم
- `/volume level` الصوت من 1 إلى 100
- `/loop mode` إيقاف/تكرار أغنية/تكرار قائمة
- `/shuffle` خلط القائمة
- `/remove position` حذف أغنية منتظرة
- `/clear` مسح الأغاني المنتظرة
- `/help` المساعدة

## مصادر الموسيقى
الإعداد الافتراضي في هذه النسخة يستخدم YouTube (`ytsearch`) عبر إضافة `youtube-source` الإصدار 1.18.2. البحث يعمل باستخدام `ytsearch:`، كما تدعم الإضافة روابط الفيديو والقوائم. قد يتعذر التشغيل أحياناً إذا حظر YouTube طلبات الخادم أو غيّر آلية التحقق؛ لا يوجد ضمان تشغيل دائم لكل فيديو. لا تضف OAuth أو رموز Google لحسابك الأساسي؛ وثائق الإضافة تحذر من مخاطر استخدام OAuth، وقد تحتاج بعض الحالات إلى إعداد مصادقة منفصل أو تحديث الإضافة.

استخدم استخدم مصادر وروابط تملك حق تشغيلها، والتزم بشروط YouTube وحقوق أصحاب المحتوى. قد تتغير آليات الحماية والتوافق، لذلك قد يتوقف بعض المحتوى عن العمل.

## استضافة 24/7
ارفع المشروع إلى VPS يدعم Docker، وثبّت Docker Compose، ثم شغّل `docker compose up -d`. يفضّل VPS بذاكرة 2GB على الأقل كبداية (قد تحتاج أكثر حسب عدد السيرفرات والاستخدام). لا تعتمد على مواقع مجانية تنام عند عدم الاستخدام. افتح المنفذ 2333 داخلياً بين الحاويات فقط؛ لا تعرضه للعامة.

## ملاحظات مهمة
- هذا مشروع أساس قابل للتطوير؛ اختبره على سيرفر تجريبي قبل دعوته لسيرفر كبير.
- لا تضع Token أو كلمة مرور Lavalink في ملفات عامة.
- `lavalink-client` واجهته تتطور؛ راجع وثائقه عند تحديث الإصدارات.
- أزرار التحكم متاحة لأعضاء نفس الروم الصوتي الذي يوجد به البوت.
